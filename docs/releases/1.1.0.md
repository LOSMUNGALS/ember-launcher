# Ember 1.1 — Your Library, Protected and Personalized

Ember 1.1 brings safer downloads and installation recovery, tools for organizing your library, manual cloud library transfers, versioned save protection, a shared Feedback board, live Steam charts, and controls for making the launcher comfortable on different screens. This release also refreshes three catalogs and adds the David Kazumi catalog, shown under its supplied name **Kazumi**.

## Download and installation reliability

- **Clear installation stages.** Downloads now distinguish downloading, extracting/installing, downloaded-but-not-installed, ready to play, and installations needing attention. Finishing a download alone does not claim the game is installed.
- **Interrupted installation recovery.** If Ember closes during installation, the next launch keeps the downloaded package and explains that installation needs confirmation. Retry installation or locate the installed executable instead of downloading the package again.
- **Resume after login.** Interrupted direct and torrent transfers recover after a successful login by default. Turn this off in Settings. Downloads you deliberately paused or canceled are left alone. External hosts may require reopening their download page and are not reopened automatically.
- **Bounded network recovery.** Transient direct-transfer failures get limited retries, and stalled connections time out. Fatal authorization, missing-file, disk-space, checksum and invalid-resume failures remain visible instead of retrying forever.
- **Source diagnostics.** Source status records refresh attempts, last successful loads and available release counts. A failed refresh keeps previously loaded data. The game picker provides a route to report a missing game through Feedback.
- **Fix this game.** The repair dialog checks a local executable, shows the previous launch failure, rescans supported installations and lets you choose a moved executable. Steam games receive a Steam-folder/App-ID check because Steam manages their executable.
- **Download screen repair.** Missing artwork stays inside its thumbnail and cannot cover the page or block Pause/Cancel. Closing the source picker also cleans up its modal overlay.

## Transfer performance and visibility

- Torrent transfers use **rarest-first piece selection** and explicit peer exchange, with unlimited engine upload/download rate settings.
- Downloads display connected peers, peers actually sending data, peers withholding data and tracker counts. Rate/ETA smoothing makes the estimate less erratic, and **Find another release** helps when a swarm has poor availability.
- Optional **UPnP/NAT-PMP router mapping** can allow incoming peers. It is off by default, requires user selection and applies to new or resumed torrents; Ember does not silently edit firewall rules.
- Direct-download progress writes occur less frequently to reduce disk overhead while retaining resumable partial files.
- An idle settings refresh loop that generated thousands of events per second has been removed.

These changes remove launcher-side waste and improve visibility; public download speed still depends on peers, hosts, routing and storage. A controlled local fixture verifies engine throughput and integrity, not the speed of every public swarm.

## A library that is easier to manage

- **Right-click game menus** provide details, favorites, management, Play, folder access and uninstall actions where applicable. Discovery cards offer Save to library.
- **Collections and play status.** Organize games into up to 20 collections, set Backlog/Playing/Finished, favorite them or hide them. Library filters find these groups; hidden entries stay out of ordinary library and Home suggestions.
- **Better search.** Search handles accents, alternative local/store names, prefixes, common one-character mistakes and transposed letters. Ctrl+K (Command+K on Mac) focuses search. Enter remembers up to 12 recent queries.
- **Custom covers.** Choose a PNG/JPEG/WebP cover in Manage game or reset it to the original. Ember copies and decodes the image into its own artwork storage, so cards and page colors can use the cover consistently.
- **Storage manager.** Scan installed folder sizes and free space. Move supported Ember-owned archive installations to another drive with file verification before the library changes and the old owned folder is removed. Steam and external installer migrations remain managed by their original tools.
- **Save-aware uninstall option.** Back up a selected save-data folder before uninstalling. Canceling folder selection cancels that combined operation.

## Your account and library across computers

- **Remember this device.** Check the option before login to save an OS-encrypted session token. Passwords are not saved. Ember validates the session with the account service before opening the library; logout removes the saved token. The updated service gives remembered sessions a 30-day lifetime, subject to expiry, password reset and access revocation.
- **Manual cloud library backup and restore.** Settings → Cloud library transfers saved games, favorites, hidden flags, collections and play status through your account. Restore merges preferences on the other computer while preserving existing installation paths. New entries remain uninstalled.
- **Duplicate and identity fixes.** Steam and local installations linked to the same game share one cloud entry; restoring applies preferences to both. Non-Steam identities remain stable across repeated transfers.
- **Session safety.** Delayed responses and cloud operations from an earlier login cannot silently continue under a replacement account or account-service connection.

Library transfers are explicit, with confirmation before replacing a backup or restoring preferences. Installed files, executable paths, download jobs, custom cover files, playtime and save files are not part of the library snapshot. This is not automatic background library merging or offline account authorization.

## Versioned saves and manual cloud saves

Open **Settings → Save protection**, choose a game, and select its actual save-data folder with the game closed.

- **Separate dated versions.** Each local backup receives its own version and SHA-256 manifest. Storage manager backup actions use the same version history.
- **Verified restore.** Ember backs up current saves before restoring, checks a staged copy, checks that current saves have not changed, and swaps the folders. The previous files also remain in the reported rollback folder. A corrupt backup does not replace current saves.
- **Cloud save upload/download.** Upload local saves to the account service, or download a cloud version as another local backup before explicitly restoring it on this computer.
- **Conflict handling.** Uploads include the last inspected cloud revision. If another computer has uploaded since then, Ember blocks the stale upload. Refresh status and choose deliberately which version to keep. Replacing a cloud version preserves that prior payload as a local backup first.
- **File safety.** Drive roots, linked folders, nested backup targets, unsafe filenames, duplicate/conflicting paths and integrity failures are rejected. Switching games quickly no longer displays the prior game's backup list.

Cloud limits are **2 MiB per game, 1,000 files per snapshot and 20 games per account**. Larger save folders can use local backups. Transfers and save-folder selection are manual; there is no universal automatic save discovery, exit-time backup or automatic save synchronization. Local versions and rollback folders are retained rather than automatically pruned. Cloud save contents live in the configured hosted account database; transport uses HTTPS, but this is not end-to-end encryption.

## Feedback inside Ember

- Browse, search and filter a shared board from the **Feedback** sidebar button. Open a post to read its discussion beside the board.
- Approved users can create posts. Only the creator and Ember administrators can reply; the server enforces this restriction.
- Administrators can mark posts **Open**, **In the Works**, **Not Happening**, or **Done/Fixed**, and delete posts.
- Paste or upload up to three images per message. Supported inputs are PNG, JPEG, WebP and GIF; large static images resize automatically. Stored attachments are limited to 512 KB each and require an approved account to view.
- The board refreshes every 30 seconds, and an open discussion every 15 seconds, with manual refresh and older-post/message navigation.
- **Attach diagnostics** adds a reviewable status block to your draft. It omits credentials, account identifiers, local paths, game/source names, URLs and raw error messages. Nothing is posted until you send it.

## Discovery, Steam reviews and artwork

- **Automatically refreshed Coming Soon and Top Sellers.** Ember uses live public Steam most-wishlisted upcoming and Top Sellers results, persists the last successful lists, refreshes in the background and offers manual refresh. Failed refreshes retain the cached list and timestamp.
- Coming Soon remains named Coming Soon. Chart data is based on Steam's configured regional results, rather than claiming an exact reproduction of SteamDB's global lists.
- **Review summaries work again.** Ember uses Valve's current public review-summary endpoint and backfills older metadata caches. Steam-linked local installations use their linked App ID, so they can show the same positive percentage, review count and summary. Unsupported or unavailable sources remain honestly labeled instead of receiving invented scores.
- Custom artwork, local Steam covers, bundled artwork, cached artwork and per-game cover colors remain supported. Placeholder artwork cannot intercept download controls.

## Monitor sizing, accessibility and notifications

- Larger desktop windows receive bounded automatic scaling, composed with Windows display scaling. Login content centers vertically and remains scrollable on shorter windows. Smaller layouts get wrapped controls and responsive card/stat grids; the sidebar can scroll.
- **Ctrl + mouse wheel** zooms in/out across login and the launcher. **Ctrl + middle-click** resets to the normal automatic size for the current monitor. The device remembers manual zoom after restart.
- **Reduce motion**, **High contrast** and stronger keyboard focus help make the UI easier to use. Settings apply to login as well as the signed-in app.
- Opt into desktop notifications for completed or failed downloads, and control the unread announcement badge. OS notification permissions and Do Not Disturb still apply. A completed-download notification does not claim installation is complete.
- Settings controls now persist safely, react immediately and reject invalid changes before writing any preferences.

## Updating and service deployment

- **Installed Windows builds:** update through Ember after this normal GitHub release is published with the matching installer, blockmap and `latest.yml`. Clients check at startup, every 15 minutes, or through Settings → Launcher updates. Existing library/download records and device settings remain in the user-data directory.
- **Windows portable/source builds:** update manually; they do not replace themselves through the installed-app updater.
- **Mac:** the Apple Silicon ZIP is for M1 and newer Macs and requires a manual update. There is no Intel build or automatic Mac updater in this release. The unsigned/unnotarized export may require macOS approval before opening.
- **Hosted account service:** deploy the matching source on the existing Render service before using the new Feedback/cloud-save features and remembered-session expiry. Keep the existing Turso database and environment secrets. Required tables are added without replacing accounts. Do not import an old account export over the existing hosted database.

## Verification

The audited source passed 116 launcher tests, 22 account-service tests and expanded Electron checks for remembered login, storage moves, library organization, saves/conflicts/restore, diagnostics, accessibility, zoom, installation recovery, Feedback, covers, source imports and the controlled updater flow. Live Steam reviews and both 100-game chart feeds responded during verification. Seven catalogs and all 28,204 parsed options survived import and restart.

Public game hosts and swarms were not all downloaded. The controlled updater test does not substitute for a real older-to-newer installed Windows upgrade. See the supplied publishing checklist and build information for the exact packaged source revision and artifact checks.
