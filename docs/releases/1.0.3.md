# Ember 1.0.3 — Shared account connection

- New builds use the shared HTTPS account service by default instead of localhost.
- Hosted requests allow up to 75 seconds for the free server to wake up.
- Connection errors and account service guidance explain how to recover.
- Existing explicitly saved service addresses remain unchanged. Users with a saved localhost address should save https://ember-accounts.onrender.com under Account service connection.

The service was reachable during diagnosis. Accounts, password hashes, approvals, and local game records are unchanged. No published release assets are overwritten.
