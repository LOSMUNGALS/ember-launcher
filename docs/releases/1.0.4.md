# Ember 1.0.4 — Catalog content inclusion

- Adult and unclassified titles are eligible for catalog discovery and recommendations. Existing review and platform filters remain available.
- Removed the Settings statement claiming those titles were excluded.
- Adult titles use the existing source matching, download selection, official artwork, trailer, description and screenshot pipelines.

This does not add new download sources or guarantee every title has media or a live download. Store age/region restrictions and unavailable metadata can limit results; no fabricated artwork, media or successful-transfer claims are added. No game payloads were downloaded for verification. Published release files remain unchanged.
