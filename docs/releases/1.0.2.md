# Ember 1.0.2 — Launcher update repair

- Fixed the Windows updater loading its CommonJS module through native ESM. Installed builds now find the updater instead of silently disabling the check button.
- Removed the Test update (refresh only) button from Settings.
- Preserved account service settings, library and download records, artwork and existing game features.

Versions 1.0.0 and 1.0.1 shipped the affected module-loading code. If Check for launcher updates is disabled, install the 1.0.2 repair once manually; an unavailable updater cannot download its own repair. Subsequent published Windows updates use the repaired updater. Source, portable and macOS builds still update manually.

The shared Turso account server changes are server-side. Continue using your existing hosted account service address and credentials. Published 1.0.1 assets and its tag are unchanged.
